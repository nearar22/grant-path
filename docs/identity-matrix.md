# GrantPath identity brief

- Mechanism signature: official grant pages plus applicant facts become a validator-audited criterion map with source and profile quote bindings.
- Product metaphor: an application folder moving through three checkpoints.
- Narrative voice: practical grant coach, short directives, no courtroom or protocol language.
- Visual grammar: warm paper, editorial typography, numbered margin path, lime readiness marks.
- Interaction grammar: progressive application sheet, source ribbon, then criterion checklist.
- Evidence story: each result line points backward to one fetched official source and, for PASS, one exact applicant statement.

## Separation from recent projects

| Layer | GrantPath | CiteGuard | RegTrace | PatchProof |
|---|---|---|---|---|
| Primary actor | funding applicant | document author | compliance team | software maintainer |
| Input journey | profile first, then official call | propositions plus authorities | framework and control evidence | specification and implementation |
| Consensus question | is the applicant ready for every published gate? | does authority text support each proposition? | does evidence cover each control? | does implementation meet fixed criteria? |
| Revision rule | applicant profile can be revised twice | add one appeal authority | evidence matrix progression | new implementation revision |
| Result | deadline plus eligibility checklist | citation support findings | control matrix | patch acceptance findings |
| Interface | vertical application path | legal citation workspace | compliance dashboard | review dossier |
